## Run 2 started: balanced injection lessons

Roshan gave the go-ahead after the claim-2 write-up.

Setup:
- **`build --all-injection --balance`** (`koottam/build.py`):
  - `--all-injection` adds every injection question in the pool past `--limit` (2,500 +
    408 = 2,908 questions).
  - `--balance` keeps as many examples of each answer as the rarest answer has, dropping
    the latest examples of the commoner one.
  - The build now prints "kept per true answer" for two-option tasks, which shows the
    filter's lean directly (run 1: A 78/78, B 37/50).
  - New test `test_balance_evens_out_answers_of_one_task_only` (26 tests).
- **No-regression check:** with the council limited to cached answers (no calls),
  `build --limit 2500` rewrote run 1's `sft.jsonl` byte for byte (sha256 `56096d55…`). The
  new flags change nothing when they're off.
- **New student** `student-balanced` → Ollama `koottam-student-balanced`.
  - `students` now skips a GGUF that isn't downloaded yet instead of failing.
  - The notebook gains `STUDENT_NAME` and `EXPORT_BASE` (off: the base never changes, and
    a re-export from newer libraries could differ while sharing the cached name).
  - It now writes `<STUDENT_NAME>.run.json`; run 1's local file was renamed to
    `koottam-student.run.json`.
- **Success checks written in Lab 02 ("Run 2") before training:**
  - attacks caught rise clearly from 37/60;
  - safe texts stay near 52/56;
  - injection beats 76.7%;
